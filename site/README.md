# Романтическая открытка для Валерии

Готовый локальный Vite-проект без Dust-зависимостей. Интерфейс адаптирован для телефонов.

## Локальный запуск

Требуется Node.js 20 или новее.

```bash
npm install
npm run dev
```

Открой адрес, который покажет Vite, обычно `http://localhost:5173`.

## Проверка сборки

```bash
npm run build
npm run preview
```

## Публикация на Vercel

```bash
npm install -g vercel
vercel login
vercel --prod
```

Запускай команды из корня проекта, где находится `package.json`. Vercel автоматически использует настройки из `vercel.json`.

Таймер настроен на 00:00 03.09.2026 по локальному времени устройства. Секретное слово: `Китя`.
